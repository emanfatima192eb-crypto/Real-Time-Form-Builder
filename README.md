
# Real-Time Form Builder

## Project Description
Real-Time Form Builder is a browser-based application developed using HTML, CSS, and JavaScript. It allows users to create, customize, save, and manage dynamic forms without using any backend or external framework.

## Features
- Add different field types including Text, Email, Number, Dropdown, Radio, Checkbox, and Date.
- Customize field labels and placeholders.
- Set required field validation.
- Live form preview.
- Save and manage multiple forms.
- Edit, duplicate, and delete saved forms.
- Submit forms and collect responses.
- Display submitted responses.
- Delete individual responses.
- Drag and drop fields to change their order.
- Store forms and responses using LocalStorage.
- Display results in both the browser and console.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start creating and managing forms.

## Storage
This project uses browser LocalStorage to save form fields, saved forms, and submitted responses.
